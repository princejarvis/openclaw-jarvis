Privacy policy

Effective October 13, 2026

This policy describes the Google integration of OpenClaw Jarvis, a personally operated OpenClaw installation maintained by the GitHub account princejarvis. It also explains the limited role of this informational website.

Google information accessed

With the operator’s permission, the assistant may access Gmail messages, attachments, labels and permitted mail settings, and Google Calendar calendars, events and related details. Requested permissions may allow reading and modifying these resources, including sending email and managing events. It receives account identity information and OAuth tokens needed to maintain the authorized connection. Only connected services and granted permissions are used.

How information is used

Google information is used to provide the operator’s requested email and calendar functions, such as finding messages, answering questions about schedules, preparing replies, and managing events. Google data is not sold or used for advertising.

Selected content may be sent to the AI provider configured in the operator’s OpenClaw installation to perform a requested task. The setup is therefore not a promise that all processing stays on the local computer. Provider processing and retention depend on the chosen provider and its account settings.

OpenClaw Jarvis’s use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. The operator must select compatible providers and settings; Google API data must not be used to develop, improve, or train generalized or non-personalized AI or machine-learning models.

Storage and retention

OAuth client secrets and account tokens for this installation are stored locally in the operating system’s keyring. They are not included in this website or its public repository. Content used in a task may also appear in local conversation history, task files, logs or backups. These copies remain until the operator removes them or the relevant retention policy expires.

Access is limited by the machine’s local account and application configuration. No absolute security guarantee is made. Any provider-side copies are subject to that provider’s retention controls.

Disconnecting and deleting data

The operator can revoke this app’s access through Google Account connections and remove its locally stored authorization. Revoking access stops future authorized API access, but does not automatically erase existing conversations, files or backups. Those copies must be deleted separately, along with any provider-side copies where supported.

This website

This is a static information site. It has no sign-in form, account database, advertising, analytics scripts or application cookies. GitHub hosts the site and may process visitor IP addresses and other request information for security and operation, as described in the GitHub Privacy Statement. The assistant’s Google data is not served by this website.

Contact and changes

For non-sensitive questions about this policy, use the project contact page. Do not include private messages, tokens or account credentials in a public issue. Personal data requests should be sent directly to the operator through an existing private contact channel. This policy will be updated if the installation’s documented practices change.

A personal OpenClaw installation. Not affiliated with Google.
