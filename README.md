# OpenClaw Jarvis informational site

A static homepage, privacy policy and terms for one personally operated Gmail/Calendar integration. No assistant runtime, Google data, or credentials are hosted here.

Published at https://princejarvis.github.io/openclaw-jarvis/ using GitHub Pages from the main branch. All visual assets and styles are local; there are no third-party scripts, fonts, forms or analytics.

## OAuth branding links

- Homepage: https://princejarvis.github.io/openclaw-jarvis/
- Privacy: https://princejarvis.github.io/openclaw-jarvis/privacy.html
- Terms: https://princejarvis.github.io/openclaw-jarvis/terms.html

Google may require proof of ownership through Search Console before verification. Publishing this website does not publish the OAuth app, verify Google branding, or remove a pre-existing refresh token expiry. Those steps are handled separately.

## Maintenance

Keep the policy aligned with the installation's actual data practices. Do not commit OAuth files, tokens, private messages, local runtime configuration, or account email addresses. Add a Google verification tag only when obtained for this site by its owner.
